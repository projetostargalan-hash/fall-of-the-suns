# ☀ Fall of the Suns

Jogo de cartas tático de fantasia (PC — Windows e Linux).

**Site oficial:** https://fallofthesuns.online

## Como jogar
1. Baixe o **atualizador** na [última versão](https://github.com/projetostargalan-hash/fall-of-the-suns/releases/latest):
   - Windows: `FallOfTheSuns.exe`
   - Linux / Steam Deck: `FallOfTheSuns-linux`
2. Coloque numa pasta só para o jogo e abra. Ele baixa o jogo, mantém atualizado e abre.

Este repositório guarda só os lançamentos (arquivos do jogo) e o site — o código do jogo não fica aqui.
